ST官方Linux移植到正点原子开发板详细过程

1. ST官方开发板的原版Linux开发包编译
1.1 获取源代码
    en.SOURCES-stm32mp1-openstlinux-5-4-dunfell-mp1-20-06-24.tar.xz

1.2 解压开发包中Linux部分的源代码
    tar -vxf linux-5.4.31.tar.xz 
	
1.3 打补丁源代码
    cd linux-5.4.31/
    for p in `ls -1 ../*.patch`; do patch -p1 < $p; done //打补丁 

1.4 生成默认配置文件
    /* 进入到 linux 内核 */
    cd linux-5.4.31/       
    
    /* 生成了.config配置文件 */
    make ARCH=arm multi_v7_defconfig "fragment*.config"
    
    /* 对.config文件打补丁 */
    for f in `ls -1 ../fragment*.config`; do scripts/kconfig/merge_config.sh -m -r .config $f; done

    /* 将 oldconfig 的所有选项都配置为 yes，最后这些配置信息都会写入到.config 文件内 */
    /* 现在的 .config 文件，已是ST官方开发板Linux配置文件的最终形态 */
    yes '' | make ARCH=arm oldconfig
    
    /* 将一份标准的ST开发板的默认配置文件.config文件，进行拷贝一份，作为自己对应开发板的一份默认配置文件的蓝本 */
    cp .config ./arch/arm/configs/stm32mp1_atk_defconfig
    
1.5 编译ST官方Linux源码
    1.5.1 先修改Makefile文件，固定两个参数，免去每次从命令行显示输入。
          Line360: ARCH = arm
          line362: CROSS_COMPILE = arm-none-linux-guneabihf-
    1.5.2 创建一个编译脚本 stm32mp157d_atk.sh 文件，以后直接执行编译脚本即可
          脚本内容为：
          #!/bin/sh
          make distclean
          make stm32mp1_atk_defconfig
          make menuconfig
          make uImage dtbs LOADADDR=0XC2000040 -j4
          赋予脚本可执行权限：
          chmod 777 stm32mp157d_atk.sh
    1.5.3 编译ST官方Linux源码，可直接执行编译脚本：
          ./stm32mp157d_atk.sh

1.6 可能需要适配板子的网络驱动
    因为网络是调试Linux系统的基础设施。正点原子有这部分的详细信息，这里省略。
	
接下来是移植部分：只涉及修改设备树文件即可完成移植过程。

1.7 获得自己开发板对应的配置文件：
    1.4 中已经获得：
	
1.8 适配设备树
	linux-5.4.31/arch/arm/boot/dts$ cd arch/arm/boot/dts/
	cp stm32mp15xx-edx.dtsi stm32mp157d-atk.dtsi
	cp stm32mp157d-ed1.dts  stm32mp157d-atk.dts
	
	vi  stm32mp157d-atk.dts
	将第 14 行原来的“stm32mp15xx-edx.dtsi”头文件改为“stm32mp157d-atk.dtsi”
	
	vi stm32mp157d-atk.dtsi
	/*
	** 1. 正点原子开发板没有集成 PMIC 芯片，因此需要删除相应信息
	**    还需要添加一些电源节点信息
	*/
	修改完成以后的 stm32mp157d-atk.dtsi 文件内容，请参考主文档的链接处。
	
1.9 将新增的设备树文件注入到编译过程中，修改Makefile文件：
	vi arch/arm/boot/dts/Makefile
	找到 “dtb-$(CONFIG_ARCH_STM32)”配置项
	在此配置项中追加 “stm32mp157d-atk.dtb” （line 1011：）
	
1.10 关闭内核模块验证（非必须）
	不是必须操作，仅为了方便调试。
	vi stm32mp1_atk_defconfig
	将下面四个参数屏蔽，使用#屏蔽
	CONFIG_MODULE_SIG=y
	CONFIG_MODULE_SIG_ALL=y
	CONFIG_MODULE_SIG_SHA256=y
	CONFIG_MODULE_SIG_HASH="sha256"
	也可以使用 make menuconfig 通过图形界面去屏蔽上面四个参数，并保存到  stm32mp1_atk_defconfig 文件。

至此，设备树文件适配完了，移植过程也完了。
可以直接编译了。Linux根目录下：./stm32mp157d_atk.sh
